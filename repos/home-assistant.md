# Home Assistant Core

家庭房间、设备、状态和服务的统一接入。

- [代码或文档仓库](https://github.com/home-assistant/core)
- 类型：外部依赖。
- 使用关系：真实家庭接入。

## 怎样使用这个仓库

独立服务；macOS 可在 Linux 虚拟机中运行 HA Container。

先在 HA 里完成管理员设置、设备集成与家庭设备导入，再让 Friday 登录并读取。设备数和实体数分别核对；连接成功不等于所有物理控制已验收。
