## 怎样使用这个仓库

静态站点，不连接家庭账号或设备。

[在线手册](https://lijunfeng722.github.io/friday-user-guide/)按入门、操作指南、参考、说明和常见问题组织。源内容为 Markdown，使用 MkDocs Material 构建；推送 main 后由 GitHub Actions 发布。

[公开下载目录](https://github.com/lijunfeng722/friday-user-guide/tree/main/docs/assets/scripts)提供启动、停止、重启及依赖安装升级工具的副本和校验清单。日常启停源码及测试在[元仓库根目录](https://github.com/lijunfeng722/friday-project-index)维护，安装器源码和回归测试在 [Friday 主仓](friday.md)维护。脚本由使用者下载后在部署电脑运行；私有服务清单不上传。操作与版本说明见[部署维护总览](../docs/operations.md)。
